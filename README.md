# Калькулятор

Браузерный калькулятор с современным дизайном.

## Деплой на Vercel

Проект готов к деплою на Vercel. Выполните следующие шаги:

### Способ 1: Через Vercel CLI

1. Установите Vercel CLI (если еще не установлен):
```powershell
npm install -g vercel
```

2. Войдите в аккаунт Vercel:
```powershell
vercel login
```

3. Задеплойте проект:
```powershell
vercel
```

4. Для продакшн-деплоя:
```powershell
vercel --prod
```

### Способ 2: Через GitHub

1. Загрузите проект в репозиторий GitHub
2. Перейдите на [vercel.com](https://vercel.com)
3. Войдите в аккаунт и нажмите "Add New Project"
4. Импортируйте ваш GitHub репозиторий
5. **Важно:** В настройках проекта:
   - **Framework Preset:** выберите "Other" или оставьте "Auto"
   - **Root Directory:** оставьте пустым (`.`)
   - **Build Command:** оставьте пустым (не требуется для статического сайта)
   - **Output Directory:** оставьте пустым или укажите `.`
6. Нажмите "Deploy"

### Решение проблемы 404

Если после деплоя появляется ошибка 404:

1. **Проверьте настройки проекта на Vercel:**
   - Перейдите в Settings → General
   - Убедитесь, что Root Directory пустой или равен `.`
   - Output Directory должен быть пустым

2. **Передеплойте проект:**
   ```powershell
   vercel --prod --force
   ```

3. **Или через веб-интерфейс:**
   - Перейдите в Deployments
   - Нажмите на три точки рядом с последним деплоем
   - Выберите "Redeploy"

### Структура проекта

- `index.html` - главная страница с калькулятором
- `vercel.json` - конфигурация для Vercel
- `package.json` - метаданные проекта

### Особенности

- Полностью статический сайт (не требует сборки)
- Поддержка клавиатуры
- Адаптивный дизайн
- Современный UI с градиентами и анимациями
- Переключатель светлой/темной темы
- Сохранение выбранной темы в localStorage
