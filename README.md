# Калькулятор

Браузерный калькулятор с современным дизайном.

## Деплой на Vercel

Проект готов к деплою на Vercel. Выполните следующие шаги:

### Способ 1: Через Vercel CLI

1. Установите Vercel CLI (если еще не установлен):
```powershell
npm install -g vercel
```

2. Войдите в аккаунт Vercel:
```powershell
vercel login
```

3. Задеплойте проект:
```powershell
vercel
```

4. Для продакшн-деплоя:
```powershell
vercel --prod
```

### Способ 2: Через GitHub

1. Загрузите проект в репозиторий GitHub
2. Перейдите на [vercel.com](https://vercel.com)
3. Войдите в аккаунт и нажмите "Add New Project"
4. Импортируйте ваш GitHub репозиторий
5. **Важно:** В настройках проекта:
   - **Framework Preset:** выберите "Other" или оставьте "Auto"
   - **Root Directory:** оставьте пустым (`.`)
   - **Build Command:** оставьте пустым (не требуется для статического сайта)
   - **Output Directory:** оставьте пустым или укажите `.`
6. Нажмите "Deploy"

### Решение проблемы 404

Если после деплоя появляется ошибка 404, выполните следующие шаги:

#### Шаг 1: Проверьте настройки проекта на Vercel

1. Перейдите на [vercel.com](https://vercel.com) и откройте ваш проект
2. Перейдите в **Settings → General**
3. Установите следующие настройки:
   - **Framework Preset:** `Other` (или оставьте пустым)
   - **Root Directory:** оставьте **пустым** (не заполняйте)
   - **Build Command:** оставьте **пустым** (удалите, если что-то есть)
   - **Output Directory:** оставьте **пустым** (не заполняйте)
   - **Install Command:** оставьте **пустым**
4. Нажмите **Save**

#### Шаг 2: Убедитесь, что файл index.html в корне

Файл `index.html` должен находиться в корне проекта (не в подпапке).

#### Шаг 3: Передеплойте проект

**Через веб-интерфейс:**
1. Перейдите в раздел **Deployments**
2. Нажмите на три точки (⋮) рядом с последним деплоем
3. Выберите **Redeploy**
4. Подтвердите передеплой

**Через CLI:**
```powershell
git add .
git commit -m "Обновлена конфигурация Vercel"
vercel --prod --yes
```

#### Шаг 4: Если проблема сохраняется

Попробуйте удалить проект на Vercel и создать его заново с правильными настройками с самого начала.

### Структура проекта

- `index.html` - главная страница с калькулятором
- `vercel.json` - конфигурация для Vercel
- `package.json` - метаданные проекта

### Особенности

- Полностью статический сайт (не требует сборки)
- Поддержка клавиатуры
- Адаптивный дизайн
- Современный UI с градиентами и анимациями
- Переключатель светлой/темной темы
- Сохранение выбранной темы в localStorage
